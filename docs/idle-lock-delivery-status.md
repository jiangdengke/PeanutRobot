# 锁屏配送中提示

## 效果

点击“立即出发”开始屏幕送餐后，锁屏出现时会在屏幕底部居中显示配送状态：

| 阶段 | 显示文字 |
| --- | --- |
| 前往点位 | `配送中...` |
| 到点等待取餐 | `请取餐...` |

末尾的点每 500 毫秒变化一次，按 `.` → `..` → `...` 循环。文字为白色粗体，底色为半透明黑色，叠加在屏保图片之上。

## 显示时机

| 情况 | 锁屏上是否显示 |
| --- | --- |
| 屏幕送餐前往点位 | 显示“配送中...” |
| 到点等待取餐 | 显示“请取餐...” |
| 取餐完成或超时，前往下一个点位 | 切回“配送中...” |
| 最后一个点位取餐完成或超时，开始召回 | 不显示 |
| 停止、上游路线抢占、出发失败等导致任务取消 | 不显示 |
| 急停按下期间 | 不显示，松开后恢复 |
| 上游下发路线、巡仓、回充、召回 | 不显示 |
| 没有配送任务 | 不显示，与原锁屏一致 |

锁屏在配送中途出现（60 秒无操作或点击“锁屏”）时会立即显示提示；配送结束时提示立即消失，锁屏本身保持不变。

## 不受影响的行为

- 锁屏触发时间、隐藏解锁方式和进入密码不变。
- 屏保图片、旋转角度和显示模式不变。
- 配送导航、到位上报、取餐等待和召回流程不变。

## 急停时的表现

按下急停后，锁屏上的“配送中...”或“请取餐...”立即消失，锁屏和屏保图片保持不变。松开急停后，如果配送任务仍在进行，提示按当前阶段重新出现。

- 急停只影响这行提示，不会取消配送任务，也不改变导航。
- 要操作机器人，仍需先解锁：2.5 秒内连续点击屏幕左上角 5 次，再输入进入密码。
- 急停状态来自 Peanut SDK 的急停按钮事件（`EVENT_EMERGENCY_STATUS_CHANGED`）。每次变化都会写入运行日志，模块为 `ESTOP`，记录 `emergencyOpen` 的值。

## 现场验证

1. 绑定点位后点击“立即出发”，等待锁屏出现，确认底部显示“配送中”且点在跳动。
2. 到点等待取餐期间，确认提示变为“请取餐”；取餐完成后前往下一个点位，确认切回“配送中”。
3. 最后一个点位取餐完成或等待超时后，确认提示消失。
4. 配送途中停止任务或下发上游路线，确认提示消失。
5. 锁屏显示“配送中”时按下急停，确认提示消失、锁屏保留；松开急停后确认提示恢复。在运行日志中确认 `ESTOP` 记录：按下时 `emergencyOpen=true`，松开时为 `false`。
