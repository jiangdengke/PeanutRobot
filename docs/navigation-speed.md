# 运行速度设置

## 默认值和范围

应用默认导航速度为 `20`，Peanut SDK 当前支持的速度参数范围为 `20-100` 的整数。

如果设备已经通过上游接口保存过速度，界面会显示设备当前保存的单点和多点速度；已有配置不会因为升级应用而被静默覆盖。

## 界面设置

1. 点击主界面右侧的“运行速度”按钮。
2. 对话框会显示当前单点和多点导航速度。
3. 输入 `20-100` 范围内的整数并点击“保存”。
4. 按钮会立即显示新的运行速度。

界面保存时会同时更新单点和多点导航速度，避免现场从单点路线切换到多点路线后出现速度不一致。

## 生效时机

运行速度保存在 App 的 MMKV 本地配置中，不需要重启机器人或 App。下一次导航开始准备路线时，App 会重新读取保存的速度并传给 Peanut SDK。

当前正在运行的路线不会因修改设置而停止、释放、重建或动态变速；新设置从下一次出发开始生效。

## 上游接口

现有上游接口仍可分别更新单点和多点速度：

```text
/robot_task/single_point_speed
/robot_task/multiple_point_speed
```

请求示例：

```json
{
  "speed": 20
}
```

上游接口更新后，主界面会刷新当前速度显示。若单点和多点速度不同，按钮显示为“单点速度/多点速度”，点击进入设置后可统一修改。
