# 上游地址设置

## 默认值

上游服务器 IP 默认为 `192.168.112.194`。设备上已保存过地址时，界面显示已保存的地址，升级应用不会覆盖现场配置。

## 受影响的端点

界面只修改 IP，端口保持固定。修改后以下 4 个上游端点全部切换到新地址：

| 用途 | 地址 |
| --- | --- |
| 到位上报 | `http://<IP>:9088/nav_arrive` |
| 配送语音 | `http://<IP>:9089/delivery.wav` |
| 状态上报 | `ws://<IP>:9096` |
| 仓库任务 | `ws://<IP>:9098` |

以下地址不受影响，它们是机器人本机地址，不是上游：

- 本机 HTTP 服务 `9095`，用于接收上游 `/robot_task/*` 指令。
- 本机取餐回调 `192.168.112.89:9088/pickup_status`。

## 界面设置

1. 点击主界面右侧的“上游地址”按钮。
2. 对话框会显示当前地址和受影响的端口。
3. 输入新的 IPv4 地址并点击“保存”。
4. 按钮会立即显示新地址。

点击“恢复默认”可直接回到 `192.168.112.194` 并立即生效。

## 校验规则

只接受 IPv4 地址，每段取值范围 `0-255`。以下输入会被拒绝并提示：

- 空值；
- 非数字，例如 `abc`；
- 段数不足或过多，例如 `192.168.1`、`192.168.1.1.1`；
- 段位越界，例如 `192.168.1.256`。

## 生效时机

地址保存在 App 的 MMKV 本地配置中，不需要重启机器人或 App：

- 到位上报、配送语音和仓库任务在每次使用时读取地址，保存后下一次触发即使用新地址。
- 状态上报是长连接，保存后 App 会主动断开并按新地址重连。

修改地址不会停止、重建或干扰当前正在执行的导航任务。

## 排查

修改地址会写入运行日志，模块为 `CONFIG`，可在日志中确认实际生效的地址和状态上报重连记录。
