# 设置入口

## 位置和密码

主界面右侧的“设置”按钮。点击后需要输入密码：

```text
0
```

该密码固定写在代码里，不能在界面修改，也和锁屏密码相互独立。

## 包含项

| 项 | 说明 |
| --- | --- |
| 上游地址 | 修改上游服务器 IP，列表中直接显示当前地址 |
| 运行速度 | 修改导航速度，列表中直接显示当前速度 |
| 修改进入密码 | 修改锁屏解锁和长按地图进入编辑所用的密码 |
| 编辑地图 | 进入地图点位编辑模式 |
| 锁屏设置 | 屏保图片、旋转角度、显示模式 |
| 运行日志 | 查看、复制、清空和导出诊断日志 |

原先分散在主界面右侧的“上游地址”“运行速度”“锁屏设置”“运行日志”4 个按钮已收进设置，主界面不再单独显示。

## 两个密码的区别

| 密码 | 默认值 | 用途 | 可否修改 |
| --- | --- | --- | --- |
| 设置入口密码 | `0` | 进入设置弹窗 | 不可修改 |
| 进入密码 | `123456` | 锁屏解锁、长按地图进入编辑 | 可在设置内修改 |

## 编辑地图的两条路径

- **从设置进入**：设置入口已验证过密码，不再二次输入密码。
- **长按地图进入**：保留原有方式，仍需输入“进入密码”。

两条路径都保留同一个限制：**机器人任务进行中禁止编辑地图**，会提示并拒绝进入。

## 注意

设置入口密码为 `0`，防护强度低于原先的 `123456`。地图点位改错会影响导航落点，建议只让熟悉现场的人员操作。
