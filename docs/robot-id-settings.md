# 机器人 ID 设置

## 默认值

机器人 ID 默认为 `3`。设备上已保存过 ID 时，界面显示已保存的值，升级应用不会覆盖现场配置。

## 受影响的指令

机器人 ID 只用于发往上游仓库任务 WebSocket `ws://<上游IP>:9098` 的 `robot_id` 字段：

| 指令 | 触发方式 |
| --- | --- |
| 回充 | 主界面“回充”按钮；启动后自动回充 |
| 巡仓 | 主界面“巡仓”按钮 |
| 召回 | 主界面“召回”按钮；屏幕配送最后一个点位取餐完成或超时后自动召回 |

`task_id`、`robot_task_id` 不随机器人 ID 变化，仍为代码内固定值。

## 界面设置

1. 点击主界面右侧“设置”，输入设置密码 `0`。
2. 点击“机器人 ID：<当前值>”。
3. 输入新的机器人 ID 并点击“保存”。

点击“恢复默认”可直接回到 `3` 并立即生效。

## 校验规则

只接受 `1-999999999` 的正整数。以下输入会被拒绝并提示：

- 空值；
- `0` 或负数；
- 非数字，例如 `abc`、`1.5`；
- 超过 9 位的数字，例如 `1234567890`。

## 生效时机

ID 保存在 App 的 MMKV 本地配置中，不需要重启机器人或 App。每次发送回充、巡仓、召回指令时读取 ID，保存后下一次发送即使用新值。

修改 ID 不会停止或干扰当前正在执行的导航任务。

## 排查

修改 ID 会写入运行日志，模块为 `CONFIG`，可在日志中确认实际生效的 ID。
