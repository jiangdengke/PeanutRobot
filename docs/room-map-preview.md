# 室内地图三栏布局

## 实现方式

Android 横屏主界面使用三栏常驻布局：

- 左栏约占屏幕宽度的 `1/6`，展示全部点位和已选点位队列。
- 中栏约占屏幕宽度的 `2/3`，常驻展示 `app/src/main/res/drawable/room_map.png`。
- 右栏约占屏幕宽度的 `1/6`，纵向排列导航、巡仓、回充、召回、刷新点位和锁屏等现有操作。

地图使用 `ImageView` 展示，`scaleType` 为 `fitCenter`。图片始终按原始宽高比完整居中显示，空余区域留白，不裁剪也不拉伸。

## 点位与操作

- 全部点位和已选点位队列均可独立滚动。
- 全部点位在窄左栏中按单列展示，继续复用原有选择和取消逻辑。
- 右侧操作继续复用原有 View ID 和点击逻辑，不改变机器人通信、导航、巡仓、回充等业务行为。
- 地图为主界面常驻内容，不再提供“查看地图”、关闭弹层或旋转交互。

当前版本仅展示地图图片，不在图片上叠加可点击点位。
