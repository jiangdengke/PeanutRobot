# 室内地图点位标注

## 实现方式

Android 横屏主界面使用三栏常驻布局：

- 左栏约占屏幕宽度的 `1/6`，展示全部点位和已选点位队列。
- 中栏约占屏幕宽度的 `2/3`，常驻展示 `app/src/main/res/drawable/root_map.jpg`。
- 右栏约占屏幕宽度的 `1/6`，依次展示配送操作、机器人操作和屏幕操作。

地图移除了中栏内部的 `8dp` 白边，使用 `centerCrop` 等比例铺满中间区域。地图不会拉伸变形；当屏幕中栏宽高比与原图不一致时，允许少量顶部或底部内容被裁切。

地图图片上方有独立透明标注层。标注坐标保存为相对于原始图片的 `normalized x/y`，绘制和编辑触摸均使用与 `centerCrop` 相同的缩放和裁切偏移，因此不会按整个 View 宽高直接拉伸坐标。

## 点位与操作

- 正常模式显示全部有效且启用的已配置点位小圆点；加载时会先忽略 disabled、坐标无效和重复 ID 标注，隐藏标注不会占用点位映射。点击左侧已映射点位后，地图使用放大的紫色定位标记和自定义名称突出当前点位。
- 未选择仓位时，点击左侧点位只更新地图聚焦并恢复列表临时选中视觉，不修改配送路线；已选择仓位时继续执行原有绑定、替换、解绑和重复占用校验。
- 未配置地图位置的机器人点位仍可正常绑定仓位和参与配送，地图配置不会修改 Peanut SDK 导航坐标。
- 全部点位和已选点位队列均可独立滚动；全部点位在窄左栏中按单列展示。
- 右侧操作依次为“立即出发、刷新点位”“回充、巡仓、召回”“副屏显示、立即锁屏、锁屏设置”，继续复用原有 View ID 和点击逻辑。
- 地图为主界面常驻内容，不再提供“查看地图”、关闭弹层或旋转交互。

## 现场编辑

1. 在机器人没有屏幕配送、App 本地导航、上游回充任务，且没有正在发送或等待 `9098` 确认的巡仓/回充/召回请求时，长按中间地图约 `3` 秒。
2. 输入现有锁屏密码，通过验证后进入“地图编辑中”状态。长按入口和密码确认都会重新检查任务状态；密码框打开期间开始任务也不能进入编辑。
3. 在“标注”下拉中选择已有标注或“新建标注”，再从“点位”下拉选择机器人点位；已有标注仍可重新关联全部点位，新建标注只显示尚未映射的点位。所有点位均已映射时点位下拉禁用并清空陈旧选择，状态区明确显示“所有点位均已配置”。地图上的超长标签会省略显示，标注下拉会及时显示修改后的完整名称。
4. 点击地图新增或移动当前标注，也可直接拖动已有标注微调位置；显示名称可在输入框中修改。
5. 编辑已有标注时切换关联点位即可重新关联。同一个机器人点位只能保存一个标注，重复关联会被拒绝。
6. “删除标注”删除当前工作副本中的标注；“保存”仅在 MMKV 明确返回成功后替换已保存配置并退出，写入失败会保留当前工作副本、选择和工具栏；“取消”恢复进入编辑前的已保存配置。

地图编辑期间，“立即出发、刷新点位、回充、巡仓、召回”不会启动任务。结构完整且输入有效的上游 `/robot_task/send_point` 或 `/robot_task/go_to_charge` 仍保持原有抢占优先级：任务启动前会退出编辑并直接丢弃未保存工作副本，不会自动保存。JSON 损坏、结构缺失、点位列表无效，或回充桩 ID 不是正整数时只记录日志并忽略；充电模块尚未就绪时会提示并保留编辑状态，这些无效任务都不会抢占地图编辑。

`9098` 对“回充、巡仓、召回”只返回请求是否已入队。当前仓库和 vendor SDK 没有能够权威对应这三类外部任务的完成信号，因此地图互斥只覆盖请求发送和等待 `9098` 确认的阶段；收到确认后不会用永久锁、固定超时或未知 SDK 状态码猜测外部任务执行周期。屏幕配送、App 本地导航和上游回充任务仍按各自可观测的可靠生命周期保持互斥。

配置通过项目现有 MMKV 和 Gson 保存在机器人本机，存储键为 `room_map_point_config`。配置包含地图版本 `root_map_v1`；地图版本不匹配、JSON 损坏、坐标越界或机器人点位已不存在时，无效内容会被忽略且不会阻断导航、仓位绑定或配送。

## 当前限制

- 不支持点击地图反向定位左侧列表。
- 不在地图上展示配送状态或实时轨迹。
- 不提供配置导入导出、跨设备迁移或后台远程配置。
- 地图版本变化后不会直接套用旧坐标，需要在新地图上重新配置。
- `9098` 巡仓、回充和召回的外部执行期互斥不属于当前可验证 MVP；如需覆盖，必须先获得能与具体任务对应的权威完成信号。
