# 调整地图与操作按钮布局

## Goal

将主界面调整为横屏三栏布局：地图居中展示并占据约三分之二屏幕，左侧展示点位选择按钮，右侧展示立即出发、巡仓等现有操作按钮，以减少打开弹层和对照点位列表的操作成本。

## What I already know

- 应用运行在横屏机器人设备上。
- 当前主界面已有点位列表、已选点位列表、立即出发、巡仓、回充、召回、锁屏等控件及对应业务逻辑。
- 本次只调整界面布局和地图展示方式，不修改机器人通信、导航协议或点位数据结构。
- 用户希望中间地图约占屏幕宽度的三分之二，左右两侧分别承载点位和操作按钮。
- 仓库现有 `acb04aae21ce9e365ccbd9596e7d1a3d.jpg` 是竖版浅色扫描图，与本轮消息中的黑白横版平面图不是同一张图。
- 用户已确认最终使用本轮附带的黑白横版平面图。

## Decisions

- 左侧点位区域继续使用现有动态点位数据和选择逻辑，并保留已选点位队列。
- 右侧操作区复用现有按钮 ID 和点击逻辑，只改变控件排列位置。
- 地图按比例居中显示，不拉伸变形，剩余空间留白。
- 地图在主界面常驻展示，移除不再需要的“查看地图”和关闭弹层交互。

## Open Questions

- 无。

## Requirements (evolving)

- 主界面使用横屏三栏布局。
- 地图位于界面中央，约占屏幕宽度的三分之二。
- 地图使用用户确认的黑白横版平面图。
- 左侧展示点位选择区域。
- 右侧展示立即出发、巡仓及其他现有操作按钮。
- 保留现有点位选择和机器人操作行为。
- 无点位时继续显示现有空状态提示。

## Acceptance Criteria (evolving)

- [x] 地图在主界面中央按比例完整显示，无拉伸变形。
- [x] 地图区域约占横屏宽度的三分之二。
- [x] 左侧能够查看并选择现有点位。
- [x] 右侧能够使用立即出发、巡仓及其他保留的操作按钮。
- [x] 原有点位选择和按钮点击逻辑无需修改即可继续工作。
- [x] `:app:assembleDebug` 构建通过。

## Definition of Done

- Debug 构建通过。
- 布局说明和 `progress.md` 同步更新。
- 明确记录改动文件和可执行回滚方式。

## Out of Scope

- 不在地图图片上叠加可点击点位。
- 不修改机器人通信、导航、巡仓和回充业务逻辑。
- 不增加地图编辑或点位坐标配置功能。

## Technical Notes

- 主要涉及 `app/src/main/res/layout/activity_main.xml`。
- 如最终采用图片资源，需要将确认后的图片放入 Android drawable 资源目录。
- 尽量保留现有 View ID，以复用 `MainActivity` 中已有的绑定和点击逻辑。
