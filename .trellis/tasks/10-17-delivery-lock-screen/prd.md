# 锁屏配送提示改版与急停修复

## Goal

v1.0.13-beta.1 实机反馈：锁屏上的“配送中...”太小、不美观；按下急停后提示没有消失。本任务把配送提示改为叠在锁屏壁纸底部的醒目卡通提示，点击“立即出发”后立即锁屏，并修复急停检测。

## What I already know

* 旧实现是锁屏底部一个 32sp 的半透明文字条，只在 60 秒无操作锁屏后出现。
* 急停没生效的原因：`PeanutSDK.subscribe(topic, callback)` 只把第一个订阅者接到数据源，后来的订阅者只登记、不回调。App 在 `initSubscribe()` 先订阅了 `BUTTON_STATUS`（`buttonStatusCallback`，只写 Logcat），`PeanutRuntime` 之后的订阅收不到数据，`EVENT_EMERGENCY_STATUS_CHANGED` 从不触发。
* 急停按钮数据格式为 `ButtonStatusApi.Bean`：`{"data":{"info":true}}`，`info` 即 SDK 的 `emergencyOpen`。
* 所有出发失败路径（充电模块未就绪、停止充电失败或超时、路线准备超时、导航错误）最终都调用 `cancelScreenCompartmentRoute()`。
* 屏幕为横屏；App 主色为紫色 `ui_primary #5A2F82`。

## Requirements

* 点击“立即出发”且配送任务创建成功后，立即锁屏并显示配送提示，挡住所有操作；仍用左上角 2.5 秒内连点 5 次 + 进入密码解锁。
* 锁屏壁纸照常显示，配送提示只占屏幕底部约 30%，垫一层从透明到深色的渐变遮罩，避开现场熊猫壁纸的五官（第一版整屏紫/橙背景经反馈与项目风格违和；放在下半屏时挡住熊猫，已下移并缩小字号）。
* 文字使用卡通字体站酷快乐体（OFL 1.1），标题为白字描边。
* 前往点位：超大“配送中...”（点循环跳动、紫色描边），下方显示“正在前往 第 N/M 个点位 · 点位名”和流动进度条。不显示图标（第二版的紫/黄餐盖图标和光圈经反馈去掉）。
* 到点等待：“请取餐...”（紫色描边），呼吸高亮的紫底白字白边“请从 X 号仓取餐”，下方显示“第 N/M 个点位 · 点位名”。两种状态色调一致，均使用主色紫 `ui_primary`。
* 急停按下期间隐藏配送提示，只留锁屏壁纸；松开后若配送仍在进行则恢复。急停不取消配送、不改变导航。
* 急停状态从 App 自己的 `BUTTON_STATUS` 回调解析，状态变化写入 `ESTOP` 运行日志并记录原始 `info`。
* 机器人还没真正开始行驶（未收到当前任务的 `STATE_RUNNING`）就失败取消时，自动解除出发时加的锁屏，方便操作员看到提示并重试。
* 配送完成或取消后隐藏配送提示；解锁后 60 秒无操作再次锁屏时，若仍在配送则重新显示配送提示。
* 标题 80sp、仓号 36sp、点位信息 24sp；内容超出底部区域时等比缩小，缩放按两种状态中较高的一种计算；所有动画在隐藏、暂停、销毁时停止。

## Acceptance Criteria

* [ ] 点击“立即出发”后马上锁屏，屏幕底部显示配送提示且不遮挡熊猫五官，主界面无法点击。
* [ ] 前往点位时显示卡通字体“配送中...”、进度文字和流动进度条动画，不显示图标。
* [ ] 到点后显示“请取餐...”和正确的仓号，取餐后切回“配送中...”。
* [ ] 按下急停后配送提示消失、锁屏壁纸保留；松开后恢复；运行日志有 `ESTOP` 记录。
* [ ] 出发阶段失败（如停止充电超时）时自动解锁并提示重试。
* [ ] 最后一个点位完成或任务取消后配送提示消失。
* [ ] `:app:testDebugUnitTest` 和 `:app:assembleDebug` 通过。

## Out of Scope

* 不改变解锁方式、进入密码和 60 秒自动锁屏时间。
* 不为上游路线、巡仓、回充、召回显示配送提示。
* 急停时不自动解锁、不取消配送。

## Technical Notes

* 新增 `view/DeliveryLockScreenView` 封装布局、文字和动画；`MainActivity` 只计算状态并调用。
* 新增纯 Java 的 `util/EmergencyButtonStatusParser` 和 `util/DeliveryLockScreenText`，补充 JVM 单元测试。
* 去掉对 `PeanutRuntime` 急停事件的依赖，避免两个来源。
