# 增加统一设置入口

## Goal

在主界面右侧用一个“设置”按钮替代散落的配置入口。点击后先输入固定密码 `0`，通过后在设置弹窗里集中修改上游地址、进入密码、运行速度、锁屏设置，并可进入地图编辑和查看运行日志。

## What I already know

现有配置入口和密码机制：

| 入口 | 当前位置 | 现状 |
| --- | --- | --- |
| 上游地址 | 右侧 `tv_upstream_server` | `beta.21` 新增，弹窗可改 IP |
| 运行速度 | 右侧 `tv_navigation_speed` | `beta.20` 新增，弹窗可改 20-100 |
| 锁屏设置 | 右侧 `tv_idle_screen_settings` | 屏保图片、旋转、显示模式、修改进入密码 |
| 运行日志 | 右侧 `tv_diagnostic_logs` | `beta.19` 起 `visibility="gone"` |
| 编辑地图 | 长按地图区域 | 需输入锁屏密码，`showMapEditPasswordDialog()` |

密码现状：

* `KEY_IDLE_LOCK_PASSWORD` 默认 `123456`，由 `getIdleLockPassword()` 读取。
* 该密码同时用于锁屏解锁 `showUnlockDialog()` 和地图编辑验证 `showMapEditPasswordDialog()`。
* “修改进入密码”已实现，位于锁屏设置弹窗内，留空表示不修改。

地图编辑约束：

* `requestMapEditEntry()` 会先判断 `mapEditMode`、`mapEditPasswordDialogShowing` 和 `isRobotTaskBusyForMapEditing()`。
* 机器人任务进行中禁止编辑地图，这个限制必须保留。

## Assumptions

* 设置入口密码固定为 `0`，写在代码常量里，不可在界面修改，也不与锁屏密码共用。
* 锁屏解锁密码和地图编辑所用的 `KEY_IDLE_LOCK_PASSWORD` 语义不变，仍默认 `123456`。
* “立即出发”“刷新点位”“回充”“巡仓”“召回”“副屏显示”“立即锁屏”仍留在右侧，属于日常操作，不进设置。
* 运行日志入口在设置内恢复可用，主界面不再单独显示。

## Requirements

* 右侧新增“设置”按钮，替代上游地址、运行速度、锁屏设置和运行日志 4 个入口。
* 点击“设置”先弹出密码框，输入 `0` 才能进入；密码错误给出提示且不进入。
* 设置弹窗提供 6 项：上游地址、运行速度、修改进入密码、编辑地图、锁屏设置、运行日志。
* 上游地址和运行速度在设置列表中直接显示当前值。
* 将“修改进入密码”从锁屏设置弹窗中独立成一项，锁屏设置只保留屏保图片、旋转角度和显示模式。
* 通过设置进入“编辑地图”时不再二次输入密码，但仍保留机器人任务进行中禁止编辑的限制。
* 保留长按地图进入编辑的原有路径及其密码验证，不改变现场既有习惯。
* 设置弹窗关闭后不影响空闲锁屏计时、导航、回充和仓位绑定行为。

## Acceptance Criteria

* [ ] 右侧显示“设置”按钮，且不再显示上游地址、运行速度、锁屏设置、运行日志 4 个按钮。
* [ ] 点击“设置”输入 `0` 可进入；输入空值或其他内容提示密码错误且不进入。
* [ ] 设置弹窗内 6 项均可打开对应界面。
* [ ] 上游地址和运行速度在列表中显示当前生效值，修改保存后返回设置可见新值。
* [ ] 锁屏设置弹窗不再包含密码输入框；“修改进入密码”独立可用，留空不修改。
* [ ] 从设置点“编辑地图”直接进入编辑模式，不再要求输密码。
* [ ] 机器人任务进行中，从设置点“编辑地图”仍提示禁止编辑且不进入。
* [ ] 长按地图仍可进入编辑并仍验证锁屏密码。
* [ ] `:app:testDebugUnitTest` 和 `:app:assembleDebug` 通过。

## Definition of Done

* 设置入口密码、各子项跳转集中且可读，没有重复的密码校验实现。
* 密码校验逻辑补充单元测试。
* Lint、单元测试和 Debug 构建通过。
* README 和现场文档说明设置入口、固定密码和包含项。
* 进度日志记录改动文件、验证结果和回滚方式。

## Out of Scope

* 不把设置入口密码做成可配置。
* 不改变锁屏密码默认值和锁屏解锁流程。
* 不新增权限分级、操作审计或设置项搜索。
* 不改动地图编辑本身的编辑、保存和取消逻辑。
* 不清理未使用 Fragment 中的遗留地址和既有换行符差异文件。

## Technical Notes

* 新增 `SettingsAccessConfig` 承载固定密码常量和校验，便于单元测试。
* 右侧被收起的 4 个按钮保留 `id` 并设为 `visibility="gone"`，沿用运行日志入口的处理方式，避免大范围改动引用代码。
* 设置弹窗用 `ScrollView` 包一列条目，条目点击后关闭设置弹窗再打开对应子弹窗，复用现有 `showUpstreamServerDialog()`、`showNavigationSpeedDialog()`、`showIdleScreenSettingsDialog()` 和 `showDiagnosticLogDialog()`。
* 从设置进入地图编辑走新的免密路径，仍复用 `isRobotTaskBusyForMapEditing()` 和 `enterMapEditMode()`。

## Risk

固定密码 `0` 的防护强度低于现有 `123456`。地图点位改错会影响导航落点，本轮按现场易操作优先，已与使用方确认。
